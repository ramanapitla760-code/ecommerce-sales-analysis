# E-Commerce Sales & Profitability Analysis

## Project Overview

E-commerce sales and profitability analysis using MySQL and Microsoft Excel.

This project analyzes sales performance, profitability, customer behavior, product performance, payment methods, returns, cancellations, and data quality.

## Tools & Technologies

- MySQL
- Microsoft Excel
- SQL
- Data Analysis
- Data Visualization

## Key Analysis

- Order status distribution
- Sales and profitability KPIs
- Revenue and profit by category
- Top 10 products by revenue
- Top 10 products by profit
- Top 10 customers by revenue
- Monthly revenue trends
- Payment method analysis
- Return analysis
- Cancellation rate
- Repeat customers
- Data quality analysis
- Product margin analysis
- SQL performance optimization

## Key Insights

The analysis focuses on:

- Overall sales and profitability performance
- Revenue and profit contribution by product category
- Top-performing products and customers
- Monthly revenue trends
- Payment method distribution
- Customer repeat-purchase behavior
- Return and cancellation patterns
- Data-quality issues such as invalid quantities and negative-margin products
